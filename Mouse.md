## MouseIn(Left, Top, Width, Height) ⇒ <code>boolean</code>
Check if the mouse position is within the boundaries of a given zone (Useful for UI components)

**Kind**: global function  
**Returns**: <code>boolean</code> - - Returns TRUE if the click occurred in the given zone  

| Param | Type | Description |
| --- | --- | --- |
| Left | <code>number</code> | Starting position on the X axis |
| Top | <code>number</code> | Starting position on the Y axis |
| Width | <code>number</code> | Width of the zone |
| Height | <code>number</code> | Height of the zone |
