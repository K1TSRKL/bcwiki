## MiniGameStart(GameType, Difficulty, ReturnFunction) ⇒ <code>void</code>
Starts a given mini game at a set difficulty and keeps

**Kind**: global function  
**Returns**: <code>void</code> - - Nothing  

| Param | Type | Description |
| --- | --- | --- |
| GameType | <code>string</code> | Name of the mini-game to launch |
| Difficulty | <code>number</code> | Difficulty Ration for the mini-game |
| ReturnFunction | <code>string</code> | Callback name to execute once the mini-game is over |
