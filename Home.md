# Bondage Club Wiki

Welcome to the Bondage Club wiki! The wiki is primarily intended as a resource for developers and contributors to the game, and a place to help new contributors get started with adding new content to the game. This is still something of a work-in-progress, and will develop over time. If you think something is missing from the wiki, or have some knowledge about a topic and would like to contribute some content yourself, feel free to get in touch with one of the developers over on [the game's Discord server](https://discordapp.com/invite/dkWsEjf).

## API Documentation

We are starting to document the data structures and the main functions of the BC game, as a help to future contributors.

### Modules

We are adding [JSDoc](https://jsdoc.app/index.html) comments to all functions in the various scripts, as we edit them. The resulting documentation pages are then collected and shared on this wiki. We hope to help all contributors with this.

The wiki markup for these pages can be automatically generated from the game's source code using scripts from the [Bondage Club Scripts](https://github.com/elliesec/Bondage-Club-Scripts) repository (note that Node.js and npm are required to do this).
